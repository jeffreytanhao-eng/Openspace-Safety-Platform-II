# 本地自有 3D 模型目录

本目录存放**本项目自有**的卫星 / 碎片 GLB·GLTF（从旧版 Openspace Safety Platform 迁入），不是第三方资源清单。

- 运行时路径：`/models/<filename>`（Vite `web/public/models`）
- 旧项目来源：`openspace-safety-platform/public/map/type/gltf`（及构建产物 `dist/map/type/gltf`）
- 态势页会读取同目录 `manifest.json`；暂无映射时 3D 仍用点云显示目录目标

请继续把自制或旧平台导出的模型放在这里；不要提交商业模型包。
