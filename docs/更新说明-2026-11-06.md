## R2-12 极区影像补齐（离线补丁瓦片）

- 成因：底图影像为 Web Mercator，覆盖止于 ±85.05°，极区露出底层亮蓝海洋，形成对称淡蓝圆。
- 方案：在 ±85° 以上叠加本地极区补丁瓦片，不使用纯色遮盖。
  - `web/public/tiles/polar/north.jpg`（2048×512，北极真彩）
  - `web/public/tiles/polar/south.jpg`（2048×512，南极真彩）
- `web/src/views/situation/cesiumEarth.ts`：新增 `createPolarCapLayers()`，用 `SingleTileImageryProvider` + `Rectangle` 建两层，挂载在影像栈最上层；文件缺失（HEAD 非 200）时静默跳过，不影响离线兜底。

验收：本地 `tiles/polar/north.jpg` / `south.jpg` 均返回 200；极区视觉确认待整体回归时人工复核。

## 追加修正（同日复验）

- **极区补丁修复**：Cesium 1.146 的 `SingleTileImageryProvider` 要求显式传入 `tileWidth/tileHeight`，缺失会抛异常并被吞掉，补丁图层实际未挂载。已补 `2048×512`；可用性探测由 `HEAD` 改为图片解码（并发初始化时 HEAD 会被浏览器中止为 `ERR_ABORTED`）。覆盖范围扩到 ±84°，与在线影像保留 1° 重叠。实测日志「极区补丁图层 2」，南极极点淡蓝缺口消失（补丁与在线影像存在轻微色调差，属数据源差异，不是缺口）。
- **侧栏更名**：`AI` → `操作事件流`，副标题 `规则聚合，非模型推断`（计划书 R2-17 原文允许改显示名）。路由 `/ai` 与入口保留。
- **交会放大态**：双方显示位置增设最小间距 0.008 场景单位（≈51 km，仅视觉分离，不参与任何计算，真实 miss 仍以数值为准）；标签改为三行——名称 / NORAD ID / 类型。

## 第二轮（参数档案 · 认领审核 · 星历归属）

### 1. 极区补丁彻底修复

对照老项目 `openspace-safety-platform` 后确认：老项目**没有内置离线底图垫层**，所以 Web Mercator 影像在 ±85.05° 之外的缺口处直接露出地球暗色，视觉上几乎看不出来。本项目此前叠加了 `NaturalEarthII` 离线底图（亮蓝海洋），缺口处透出的正是这层亮蓝，形成对称淡蓝圆盘。

修复：
- `web/src/views/situation/cesiumEarth.ts`：仅在**在线影像不可用**时才加载离线底图（`createOfflineBaseLayer()`），正常联网时不再垫层。

- `SingleTileImageryProvider` 显式传入 `tileWidth/tileHeight`（Cesium 1.146 必需），可用性探测改为图片解码（并发初始化时 HEAD 会被浏览器中止为 `ERR_ABORTED`）。
