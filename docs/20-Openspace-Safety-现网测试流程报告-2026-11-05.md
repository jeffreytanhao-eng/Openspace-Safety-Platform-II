## 4. 不符合原计划书要求（偏差）

| # | 计划书要求 | 现网表现 |
|---:|---|---|
| 1 | 侧栏信息架构；**不做/砍侧栏 AI**；可砍独立轨道页 | 仍有 **AI、轨迹**；命名为「目标/交会/文档」；无独立「报告」导航 |
| 2 | 态势用 **黄 / 橙 / 红** 云表示危险性 | UI 文案多为「高危/警告/关注」；后端 level **仅 red/low** |
| 3 | 系统日更 TLE+CDM+**AOE**；应有调度 | GP/CDM 曾**手动**成功；AOE 未配；**未见 cron**；admin 无日更面板 |
| 4 | `catalog`/`health` 健康字段可信 | `catalog/stats` 仍写 **10-28 sidecar**，与 health **11-04** 矛盾 |
| 5 | 总览去 mock、真驾驶舱 | **STAGING / Stage 1 mock** 文案残留；KPI 未组织化 |
| 6 | 路径草图 `/cgi/screen`、`/cgi/jobs/daily-fetch` | 实际 `/cgi/screens`、`/cgi/jobs/daily-fetch/status` |
| 7 | 未登录受保护 API 返回 401 | **`/cgi/events` 匿名 200** |
| 8 | 超管写操作有 audit | audit **空** |
| 9 | 星网/运营商可发现本星座 | 无「星网」别名；态势芯片无国网；须知 `HULIANWANG DIGUI` |
| 10 | 认领后可筛查（作业链） | 认领成功但筛查报缺两行根数（与详情可见 TLE 矛盾） |
| 11 | 配额展示相对档位上限 | 托管页显示 **n/n**（如 231/231）而非 n/500 |
| 12 | P0 刻意不做完整 override UI | 现网**已有**配额 override + flags（超前，属范围偏差） |
