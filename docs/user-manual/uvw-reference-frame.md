# 机动 Δv 的 UVW 标注

星历表「方向」列、态势机动卡片和地球上的 Δv 第二行，统一写成：

```
Δv = (0.000 U, 0.093 V, 0.000 W) m/s
```

数字在前、空格、轴字母；分量之间用半角逗号；外层一对半角括号；单位 `m/s` 只在末尾写一次。中文界面与英文界面的矢量本身相同。`|x| < 1e-6`，或不足该次机动 `|Δv|` 的 0.1% 时，分量写成 `0.000`；其余非零且绝对值小于 `0.001` 时用科学计数法。缺少加速度时矢量仍为「—」。模长与能量标记单独保留，例如 `0.076 m/s（加速）` / `（减速）`，英文为 `(Accel)` / `(Decel)`；地球上第一行仍是 `|Δv| …`。星历表「方向」列标题和态势卡片在「方向」后附灰色小字：`U 径向，V 沿迹，W 面外`（英文 `U radial, V along-track, W cross-track`），不写进矢量那一行。

## 轴的定义

界面使用 UVW（与 RTN / RSW 同一族），不在产品界面展开轴的全称：

| 字母 | 含义 | 英文 |
| --- | --- | --- |
| U | 径向，沿 r̂ 向外 | Radial |
| V | 沿迹 | Along-track |
| W | 轨道面外，沿 r̂×v̂ | Cross-track |

## 与文件参考系的对应

- **RTN / RSW / UVW**：R↔U，T↔V，N↔W。文件里的 (R, T, N) 即为 (U, V, W)。显示时仍走同一套投影，避免另开一条特殊路径。
- **NTW**（OCM 机动常用 `NTW_ROTATING`）：T 沿速度，W = r×v，N = T×W（面内法向）。近圆轨道上 N 约等于 U，偏心轨道上一般不等于径向。界面**不会**把 NTW 的 (N, T, W) 直接标成 U、V、W，而是在机动历元把文件坐标系中的 Δv 先变换到 ECI，再投影到 Û、V̂、Ŵ。
- **惯性系**（如 EME2000 / J2000）：同样先取 ECI 分量，再投影到当地 UVW。

蓝色「>」仍按文件坐标系的显著分量定向（单轴统一朝向，有偏离时交错），与上述显示用的 UVW 投影相互独立。
