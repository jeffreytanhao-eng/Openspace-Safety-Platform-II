# 态势位置不确定度管道

在三维态势中，选中一条星历后，可勾选侧栏「显示不确定度管道」，由 Three.js 层沿**整段**星历绘制一条连续的位置不确定度管道（默认不勾选；勾选后默认为 1σ，可切 3σ）。管道截面取该时刻位置椭球与垂直于轨道平面的交线（椭圆）。为便于在跟星视角下辨认粗细，**横向截面可放大绘制**（侧栏「1σ 截面放大」可选 1× / 5× / 20×，默认 5×），3σ 截面为所选倍率的 3 倍。放大只作用于横向截面，沿轨方向仍按真实位置铺展；该倍数与镜头远近无关，也没有公里级视觉下限。文件开头米级 σ 放大 20 倍后仍可能很细；中段约 0.5 km 的截面放大后约 10 km，不会大到占掉地球一角。

> 管道的轴心就是卫星轨道（截面环心 = 状态点，不存在横向偏移），管壁必然落在轨道线两侧之外。整段多圈星历一次画满时，近距视角会看到多层走廊叠加、像是"紫色跑到轨道外面"，因此相机贴近轨道（视距小于约 10 倍当地管半径）时填充自动淡出到 5%，离开后恢复。

外观为暗靛紫（`#3b1a78`）半透明填充管道，无边缘线框/虚线，以便和轨道浅蓝 `#81d4fa`、机动琥珀 `#ffb454` / 金色管 `#ffd166` 区分。管道画在 3D 卫星模型之下（深度测试开启，填充不写深度）；被模型挡住一段是预期现象。机动管段与蓝色「>」仍按原逻辑绘制。

英文对应句：The purple tube is the uncertainty trajectory corridor; 1σ / 3σ can be switched. It spans the whole track and fades out when the camera gets close. Cross-section width is drawn at N× the true 1σ (3σ uses 3× that scale); along-track length is true scale, not a physical measurement.

## 数据

- **文件协方差**：解析 OCM 的 `COV_START` / `COVARIANCE_START` 块（`CARTPV` + `LTM` 21 项下三角，或 `FULL` 6×6）。历元对齐到最近状态（60 s 内）。提取 3×3 位置子块做特征值分解，σ = √(特征值)，单位 **km**（矩阵单位为 km²）。管道逐站直接取该状态自带的协方差，不再经过稀疏目录插值；只有在逐点 COV 已缺失时才回退到稀疏样本之间按协方差矩阵插值再重新对角化。
- **参考系**：RTN / UVW / RSW 转到 ECI；`COV_REF_FRAME` 为 ITRF 时，用与轨迹相同的 GMST 绕 Z 旋转（位置块精确）。惯性系不转。
- **龄期回退**：没有完整 COV 时，使用与筛查相同的 TLE 龄期经验模型（0 h / 6 h → 1 km，72 h → 11.7 km，168 h → 38.5 km，上限 200 km；σ_R = σ_N = max(0.2, 0.1·σ_T) 公里）。此回退只用于地球上的不确定度显示，不改变官方 CDM Pc 或筛查任务的计算。
- 逐点 6×6 仍会在写入本机缓存前去掉以免撑爆 IndexedDB；稀疏主轴样本与 `hasCov` 一并存入 IndexedDB，激活星历时若样本缺失会再从仍保留的逐点 COV 重建（若 COV 已被去掉，需重新载入文件才能恢复文件主轴）。

## 显示

侧栏「不确定性」把「显示不确定度管道」、1σ / 3σ 与「1σ 截面放大」（1× / 5× / 20×，默认 5×）放在同一行，图例在下方。未勾选时 1σ / 3σ 与倍率选择均为灰色不可用；勾选后可切换，并按所选 σ 与倍率重建管道。管道**每个星历状态一个截面**（7 天 60 s 文件即 10,081 个），轴线与轨道线使用同一组状态顶点，实测偏差在浮点量化量级（< 1 m）；截面在垂直于轨道的平面内取椭圆，按该平面 2×2 二次型的主轴生成长短半轴，长短轴端点必落在截面顶点上（早期等角度极径采样在 15:1 的扁截面上会漏掉长轴尖端）。1σ/3σ 与放大倍率只把长短半轴线性放大，截面形状与轨道位置不变。沿迹轴只会使倾斜椭球的切片略鼓或略扁，不会把整段直径按沿迹误差加粗。文件里各点 σ 不同，管道就会有的地方细、有的地方粗。世界尺度与镜头高度无关，不会按像素或视距去放大；只有不透明度会随镜头贴近程度淡出。低配设备降低径向顶点数。

这是沿轨迹扫过的示意走廊，不是整条弧上的联合概率体积。

API：`GET /cgi/ephemerides/uncertainty?path=...` 返回同样口径的稀疏样本（需登录）。
