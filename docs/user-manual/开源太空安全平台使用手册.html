1. 简介与登录

开源太空安全平台是面向在轨目标碰撞安全的作业辅助控制台。你可以在这里管理关注或认领的目标、浏览星历、查看交会事件、发起筛查、进入三维态势，并把报告或星历源文件存进「我的文档」。

打开平台后先进入登录页。在「账号 / 邮箱」和「密码」中填写凭证，点击「登录」。还没有账号时，可切换到「注册」。

  • 登录成功后，普通与 VIP 账号会进入「总览」。
  • 顶部右侧可以切换「中文 / EN」，并随时点「退出」结束本次会话。

2. 界面与导航

登录后，左侧栏是主要功能入口，当前顺序为：总览 → 目标 → 星历 → 交会事件 → 筛查 → 态势 → 我的文档 → 设置。顶部显示平台名称、当前单位与档位、账号入口，右下角是 UTC 与北京时间。

  • 可用左上角「搜索导航…」快速过滤栏目。
  • 点右上角「账号」进入个人资料与改密；VIP 账号还会看到当前单位名称和金色 VIP 标识。

3. 总览

总览是登录后的工作台。上方是关键指标（目标数量、未来 24 小时 / 7 天交会、今日筛查、星历可用），左侧是资产清单与数据源健康，右侧是关注事件，左下角是报告下载。

  • 资产清单：当前已认领或关注的目标。可点「管理」跳到目标页。
  • 关注事件：与这些目标相关的系统 CDM 交会；可用 24h / 3d / 7d 切换时间窗。
  • 数据源健康：查看 GP 根数日更、CDM 公报日更、AOE 历算是否正常。
  • 报告下载：选择报告类型（如「组织日报摘要」或「关注事件包」）和时间窗，点「下载」保存到本地，或点「存到我的文档」。存档时，文件名会自动带上保存时间。

若当前时间窗没有可导出的事件，系统会提示未生成文件，不会写入空文档。

4. 目标

「目标」页列出你已经关联的在轨目标，可检索名称或 NORAD，并维护档案信息。

  • 关注目标：立即生效，可供学习 / 教学 / 模拟科研；不能修改档案参数，也不能绑定星历。普通账号使用这个入口。
  • 认领目标（业主认领）：仅 VIP 可发起。提交后需平台超管审核，通过后才能维护档案参数、上传或绑定星历。
  • 同一个目标若已有业主，其他人仍可添加关注。
  • 页面右上角会显示认领 / 关注的当前用量与上限。

5. 星历

在「星历」页浏览、预览本地星历文件。左侧是文件列表，右侧是预览详情。

  • 点击左侧文件即可在右侧查看格式、点数、步长、有效期、协方差和来源。
  • 需要在三维视口中查看该目标时，点右上角「关联至态势」。
  • 要把源文件留存到个人或共享文档库，点「存到我的文档」。保存后的文件名会自动带上存储时间。
  • 「查看原文件」会打开原始内容（压缩文件会自动解压显示）。
  • VIP 可上传本单位已认领目标的星历；基础账号不能上传星历。

6. 交会事件

「交会事件」汇总接近事件。顶部可切换数据源，并用时间窗、风险档和「全部交会 / 我的关注/认领」缩小范围。点击一行进入详情。

  • 数据源可在 CDM、TLE、Ephem、AOE 之间切换；也可「导入 CDM」补充报文。
  • 风险档包括高危、警告、关注、低，便于先处理更紧迫的事件。
  • 详情页可查看主目标 / 次目标轨道要素，并点「在目标页查看」跳转档案。
  • 需要对照三维几何时，点「打开态势可视化」。
  • 时间线中的「查看原文」用于核对该条 CDM 报文；需要时也可导出事件。

7. 筛查

「筛查」用于对已托管目标发起自主交会计算，结果按黄 / 橙 / 红分级。左侧新建任务，下方是近期任务，右侧展示选中任务的事件。

  • 填写预报窗口（小时）、最小距离门限（km）和硬体半径 HBR（m），选择主星状态源与副星对照源。
  • 主星范围默认是「全部目标」；目标较多时可勾选「分批选择」。
  • 点「发起筛查」后，任务会出现在下方列表。计算中的任务会自动刷新；完成后点击即可查看黄 / 橙 / 红事件。
  • 「根数自检」可检查目标是否已有可用根数，避免因数据缺失导致空跑。
  • 发起筛查与重算需要 VIP；基础档会看到相应提示，不能提交新任务。

8. 态势

「态势」提供三维地球视口，用来观察目标、轨道和交会几何。

  • 底部时间条可播放或暂停仿真，并在 0.1× / 1× / 10× / 60× 之间切换倍率。
  • 「交会事件」打开黄 / 橙 / 红交会云；点选事件可进入双方近景。
  • 左侧「太空目标列表」检索并点亮目标；右侧「星历文件解析」用于分析星历。
  • 「复位」回到初始镜头；「初始化窗口」只重建三维视口。

9. 我的文档

「我的文档」分为左侧列表和右侧阅读栏。右上角显示当前用量和上限。

  • 普通账号：个人文档空间，最多保存 50 份。
  • VIP 账号：同一单位共享 500 份。同事能查看、下载彼此保存的文档，但不能删除别人保存的文件。
  • 阅读栏支持文本、表格和本手册这类带图 HTML；其他二进制文件可点「下载」后本地打开。
  • 自己保存的文档可以「删除」或「下载」。从总览或星历点「存到我的文档」时，文件名会自动加上保存时间，避免互相覆盖。

10. 设置与账号

「设置」用来维护默认碰撞参数（CA），例如硬体半径、接受 Pc、筛查距离阈值、协方差模式和 Pc 方法。管理员保存后，本单位后续筛查与重算会采用这些默认值。

  • 每位用户还可以配置最多 2 组「我的自定义参数」，仅本人可见，发起筛查或重算时按需选用。
  • 右上角进入「账号」后，可修改密码（需填写原密码和新密码）。
  • 这里也能看到当前档位、配额用量。普通账号如需升级 VIP，请通过页面提示联系平台管理员开通。
