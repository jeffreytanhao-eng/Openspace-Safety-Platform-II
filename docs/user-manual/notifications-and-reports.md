# 通知与报告：三种通知渠道配置说明

「设置 → 通知与报告」可以把每天的碰撞预警日报和分级变化提醒，自动推送到你们自己的系统、邮箱或钉钉群。配置一次，之后每天自动发送，也可以在页面上随时手动生成、重发。

页面分为四块：

- **渠道**：已经配置好的通知方式，可编辑、测试、删除。
- **报告预览**：查看最新一份日报。
- **报告与投递记录**：按日期查看历史报告，可重发。
- **投递记录（审计）**：每次发送的时间、渠道、结果和失败原因。

三种渠道可以同时配置，也可以只配一种。

---

## 一、先准备好「地址」和「密钥」

三种渠道分别需要不同的材料，这些材料都来自**接收消息的那一端**，平台不会替你生成。

### 1. Webhook

适合把预警数据接到你们自己的告警平台、工单系统、消息中台或内部系统。

**Webhook URL 从哪里来？**

- 如果对接的是公司内部系统：联系该系统管理员，在系统的「开放平台 / 集成管理 / 回调地址 / Webhook 设置」里新建一个接收地址，复制生成的 URL。
- 如果对接的是第三方平台（企业微信、飞书、Slack、自建机器人等）：在对方的「机器人 / 自动化 / 集成」页面添加一个 Webhook，复制它给出的地址。
- 该地址必须是对方提供的、可以直接接收平台推送的完整网址（以 `http://` 或 `https://` 开头）。

**签名密钥从哪里来？**

- 签名密钥用于让对方确认「这条消息确实来自 Openspace Safety」。它不是平台自动生成的，而是**双方事先约定的一个字符串**。
- 如果对方系统在创建 Webhook 时会生成一个「密钥 / Secret / Token」，直接复制过来填入即可。
- 如果对方不校验来源，这一项可以留空。
- 填写后平台会在每次推送时附带签名信息，接收方按同样的密钥校验即可。具体校验方式由对方系统管理员处理，配置人员不需要了解。

**需要对方配合确认的事：**

- 对方地址能从公网访问，并且允许接收平台推送的数据。
- 对方收到数据后返回「成功」响应，平台才记为投递成功。
- 如果对方有 IP 白名单，请让对方放行平台服务器地址。

### 2. 邮件

适合发给值班邮箱、班组邮箱，作为留档和抄送。

**收件邮箱从哪里来？**

- 就是你们希望接收日报的邮箱地址，例如 `duty@example.com`。
- 一个渠道只能填一个邮箱。需要发给多人时，为每个邮箱各建一个邮件渠道。

**需要注意：**

- 邮件通道需要平台管理员在服务端开通。如果页面顶部提示「邮件通道未启用」，说明服务端还没有配置发件邮箱，请联系平台管理员开通后再使用。
- 开通前可以先把渠道建好，但发送时会显示「跳过」，不会真正发出邮件。

### 3. 钉钉

适合发到值班群，做到即时提醒。

**机器人 Webhook 从哪里来？**

1. 打开要接收通知的钉钉群。
2. 点击群右上角「群设置」→「机器人」→「添加机器人」。
3. 选择「自定义」机器人，按提示创建。
4. 创建完成后复制它给出的 **Webhook 地址**（以 `https://oapi.dingtalk.com/robot/send?access_token=...` 开头）。

**加签密钥从哪里来？**

1. 在创建机器人（或修改机器人）时，找到「安全设置」。
2. 勾选「加签」，页面会显示一串以 `SEC` 开头的密钥。
3. 复制这串密钥，填到平台渠道表单的「加签密钥」里。

**其他安全设置：**

- 如果机器人安全设置选择的是「自定义关键词」，请把关键词设置为消息中一定会出现的内容，例如 `Openspace`。平台发出的消息标题固定以 `[Openspace Safety]` 开头，因此这个关键词一定能匹配。
- 「加签」和「自定义关键词」可以只选一种，也可以同时选。选择加签时，务必把密钥填完整，否则钉钉会拒收。

## 二、新建一个通知渠道

1. 进入「设置 → 通知与报告」。
2. 在渠道表单的「类型」中勾选一种渠道：Webhook、邮件或钉钉。可以同时勾选多种，保存时会按类型分别建立渠道。
3. 填写「地址」：
   - Webhook：粘贴 Webhook URL。
   - 邮件：填写收件邮箱。
   - 钉钉：粘贴机器人 Webhook。
4. 按需填写「签名密钥」或「加签密钥」：
   - Webhook 的签名密钥可选，对方不校验时留空。
   - 钉钉选择加签时必须填写。
5. 选择「日报内容」，决定日报里包含哪些部分，默认三项全选：
   - **事件概览**：红、橙、黄、灰各级事件数量。
   - **分级变化**：与上一份日报相比，新增高危、升级、降级、已消除的条目。
   - **高危事件**：窗口内需要重点关注的事件，含交会时刻、碰撞概率和最近距离。
6. 设置「通知设置」：
   - 勾选 **每日发送日报**：每天自动收到一份日报。
   - 勾选 **分级变化**：出现新增高危或等级升级时，额外收到一条提醒。
   - **变化通知最低等级**：只对上面的「分级变化」提醒生效。选择「黄·关注」表示黄级及以上都提醒；选择「橙·警告」则只提醒橙级和红级。日报不受这一项影响。
   - 两项至少要勾选一项。
7. 保持「启用该渠道」勾选，点击「保存渠道」。

保存后，渠道会出现在上方列表中。

## 三、测试并确认能收到

每个渠道右侧都有「测试」按钮。点击后会立即发送一条样例消息，内容为：

> 红 0 · 橙 1 · 黄 2 · 灰 5，标注为测试投递。

请根据结果判断：

- 页面提示「测试投递成功」，且对方确实收到：配置完成。
- 页面提示「测试投递失败」：展开「投递记录」查看错误原因，常见原因是地址填错、密钥不一致、钉钉机器人关键词不匹配、对方服务未放行。
- 提示「测试投递已跳过」：渠道未启用，或邮件通道尚未开通。

测试成功后会刷新该渠道的「上次成功」时间；失败则记录「上次错误」，便于后续排查。

## 四、日报与分级变化提醒

### 每日日报

- 平台每天自动生成一份日报，并发送给所有启用了「每日发送日报」的渠道。
- 日报统计最近一天到未来三天的碰撞预警，按红、橙、黄、灰分级汇总。
- 如果你们已经上传或托管了目标卫星，日报只统计与这些目标相关的事件；没有托管目标时，统计系统池全量事件。
- 日报同时会按日期存档到「我的文档」，可随时回看或下载。

### 分级变化提醒

- 只有当某个事件的等级**升高**（例如黄变橙、橙变红），或**新出现**黄级及以上事件时，才会发送提醒。
- 等级降低或事件消除不会单独发提醒。
- 提醒内容只包含「分级变化」这一段，即使你在「日报内容」里没有勾选分级变化，提醒也照样会带上变化明细。
- 是否发送由「变化通知最低等级」决定。

### 手动生成与重发

- **立即生成并投递**：按当前数据生成今天的日报，并发送给所有启用的渠道。同一天重复点击会覆盖当天报告并重新发送。
- **重发**：在历史报告列表中选择某一天，把当天报告重新发给当前所有启用的渠道。重发不会重新计算数据。

## 五、投递记录怎么看

「投递记录（审计）」按时间倒序列出每一次发送，包含渠道、类型、状态、尝试次数和错误信息。

| 状态 | 含义 | 处理建议 |
| --- | --- | --- |
| 成功 | 对方已确认收到 | 无需处理 |
| 失败 | 多次尝试后仍未送达 | 查看「错误」列，核对地址、密钥、关键词或对方服务状态 |
| 跳过 | 渠道已停用、组织未开通 Webhook 推送，或邮件通道未开通 | 启用渠道或联系平台管理员开通 |

类型列会标明本次是「日报」「分级变化」还是「测试」，便于区分。

## 六、常见问题

**列表里的地址为什么显示成 `https://xxx/****`？**
出于安全考虑，页面只显示地址的域名部分，路径和参数会被隐藏。编辑时地址框留空表示沿用原地址，不会把真实地址覆盖掉。

**编辑渠道时，签名密钥要不要重新填？**
不需要。编辑时密钥留空表示保持不变；只有确实要更换或清除密钥时才需要填写。

**Webhook 显示成功，但对方说没收到数据？**
平台以对方返回成功响应为准。请对方检查是否在返回成功之前就把数据保存下来，以及是否有字段过滤或路由规则丢弃了消息。

**钉钉群收不到消息？**
先点「测试」。如果失败，依次检查：机器人是否被移出群、Webhook 是否复制完整、加签密钥是否正确、机器人若设置了自定义关键词，消息标题是否包含该关键词。

**收不到分级变化提醒？**
确认渠道勾选了「分级变化」，且变化的等级不低于「变化通知最低等级」；同时确认当天确实发生了等级升高或新增高危事件。

**日报内容少了一段？**
检查该渠道「日报内容」的勾选。分级变化提醒只包含变化段，属于正常现象。

**一个群或一个邮箱能配多个渠道吗？**
可以。每个渠道独立设置内容与最低等级，互不影响。

**渠道暂时不想用，要删除吗？**
不必。取消勾选「启用该渠道」后保存即可停发，历史记录仍会保留；需要时重新启用。
