## R0 · 阻塞与安全（2026-11-05）

### R0-1 强制鉴权 `/cgi/events` 及同类泄露面

- `api/src/routes/events.ts`：`GET /events`、`GET /events/:key`、`GET /events/:key/cdm/:cdmId/raw`、`POST /events/pc-compare` 全部由 `optionalAuth`/无鉴权改为 `requireAuth`。
- `api/src/routes/catalog.ts`：`/catalog/tles`、`/catalog/cdms` 改为 `requireAuth`；`/catalog/stats` 保持公开（仅聚合摘要）。
- `api/src/routes/satTle.ts`：`/constellation`、`/tle_lines`、`/detail/:noradId` 改为 `requireAuth`。
- `web/src/api/events.ts`：四个调用补 `Authorization` 头，避免后端强制鉴权后前端页面失效。
- 隔离口径不变：组织账号可见「系统池 + 本组织 customer」，超管（无 org）仅见系统池。

验收（本地 1235 dist API 实测）：
- 匿名 `GET /cgi/events` → `401 {"code":401,"msg":"未登录"}`。
- 组织 token `GET /cgi/events?limit=3` → 200，返回系统池事件。
- `web/src/api/screens` 等原有 token 调用无回归。
